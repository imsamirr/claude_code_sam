# Competitor breakdowns: Hollow Socks + OneCompress

All 20 ads come from the competitor pool: video, running for at least 30 days, ranked by impressions, variants collapsed. Every source file is 720×1280 (hollow_socks_10 is 720×900, i.e. 4:5). All pixel sizes below are normalised to a 1080-wide frame (1080×1920), as `measure_text.py` does. "Line height ≈ N px" is the height of the glyph band, which is roughly cap height plus descenders. "% from top" is the vertical position. Scene detection misses jump cuts that happen on a static set (hollow_socks_02/04/06) and soft cross-dissolves (onecompress_01/04). Where that happens, the real cut rate from visual checks is given next to the detected one.
